# Radar Signature Analysis

### November 2024 - December 2024

![Radar Signature](/Images/portfolio/radar_signature-1400.webp)

I developed a system for using an array of receiving antennas to extract the Eigun-frequencies of a given aircraft in order to make inference about what type of craft it is. This type of technology could be useful in military and civilian applications for applications such as Identity, Friend or Foe (IFF) detection.

I completed this work for my final project in my Linear Algebra class at Olin College of Engineering.
